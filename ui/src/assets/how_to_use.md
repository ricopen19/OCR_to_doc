できること
画像/PDF をローカルで OCR して、Markdown / Word / Excel へ変換します。レイアウトは可能な範囲で保持しつつ、最終的な微調整は Office 側で行う想定です。

クイックスタート
1. 「実行」画面でファイルを追加します（複数選択可）。
2. 出力形式（md/docx/xlsx/csv）を選びます。
3. 「処理を実行」を押して完了まで待ちます。
4. 「結果」画面で生成ファイルを開く/保存します。

おすすめ設定
まずは軽量な設定で試して、必要なときだけ重くします。
・処理モード: まずは lite（速い）。精度が必要なら full。
・表出力モード: 通常は layout。データ集計を扱うなら table を試す。
・Excelメタシート: ON（生成物の情報を残す）。

結果の見方
・「結果」画面に生成ファイル一覧が出ます。
・プレビューは現状 Markdown テキストのみです（OCRしたテキストのコピペ可能ですが、docx/xlsx はファイルを開いて確認します）。
・「別名保存」で任意の場所へコピーできます。

注意点
・OCR 結果には誤認識が含まれる可能性があります。最終成果物は必ず目視で確認してください。
・レイアウトや表は入力によって崩れることがあります。必要に応じて手動調整してください。

ローカル処理
本アプリは基本的にローカルで処理します。
